# 📦 Controle de Estoque

Sistema de controle de estoque desenvolvido para praticar e aplicar conhecimentos de HTML, CSS, JavaScript e Supabase.

## 🚀 Funcionalidades

- Cadastro de produtos
- Visualização dos produtos cadastrados
- Pesquisa de produtos
- Aumento e diminuição da quantidade em estoque
- Edição de produtos
- Exclusão de produtos
- Aviso visual para produtos com estoque baixo
- Interface adaptada para dispositivos móveis

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Supabase

## 📚 Sobre o projeto

Este projeto foi desenvolvido como parte do meu aprendizado em programação, com o objetivo de criar uma aplicação funcional de controle de estoque e praticar a integração entre JavaScript e banco de dados.
